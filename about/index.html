About This Project

This Pokedex application was an assessment project aimed at exploring my capabilities of Vue.js and Nuxt 3.

This Pokedex app was built using:

  • Vue.js 3 with Composition API
  • TypeScript for type safety
  • Nuxt 3 for routing and application structure
  • Pinia for state management
  • Custom CSS using BEM methodology
  • Vitest for unit testing

The app integrates with the PokeAPI to provide comprehensive Pokémon data, with features like searching, filtering by type or weakness, and detailed Pokémon information pages.
